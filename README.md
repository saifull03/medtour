# 🏥 Medical Tourism Management System

> A complete **MySQL / MariaDB database system** for managing medical tourism services,
> combining healthcare management with travel and support services.

---

## 📌 Project Overview

The **Medical Tourism Management System** is designed to manage patients traveling
for medical treatment while integrating tourism-related services such as
**hotel booking, transport management, and visa processing**.

This repository mainly focuses on a **well-structured relational database design**
using **MySQL**, suitable for academic and real-world use.
